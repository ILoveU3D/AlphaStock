|---|---|---|
| 企业当前状态 | 环境状态 | s |
| 管理层资本配置 | 策略 | π(a\|s) |
| 自由现金流 | 奖励 | r_t |

| 内在价值 | 最优价值函数 | v*(s)=E[Σ γ^t r_t] |

## 论证

Sutton & Barto 第3-4章给出价值函数的标准定义：v_π(s) = E_π[Σ_{t≥0} γ^t r_{t+1} | S_t=s]。逐项翻译成投资语言，就是内在价值的教科书定义——未来所有自由现金流的折现和。关键不是"DCF 也能这样看"，而是方向反过来：**DCF 的合法性不来自金融传统或大师权威，而来自序列决策数学本身**。在马尔可夫结构下，任何"未来收益现值"的算子必然满足贝尔曼方程 v(s)=E[r+γv(s')]——递归分解是数学定理，不是建模选择。这给 dcf-universal-law 补上了它一直缺的地基：它之所以是唯一公理，不是因为巴菲特说了四十年，而是因为竞争性定价公式在数学上无处可去。

## POMDP 层：安全边际与能力圈的数学户口

真实投资环境是部分可观测的（第17章 Frontiers 的部分可观测一节）：状态（企业的真实生成机制）不可直接观测，投资人拿到的是财报——延迟、带噪、且由利益方编制的观测值。两个经典概念的数学形式由此落地：

- **安全边际** = 对观测误差的系统性补偿。状态估计有噪声，买价必须让"估计错了"仍有活路——格雷厄姆的操作从来不是心理安慰，是 POMDP 下的稳健决策。
- **能力圈** = 观测质量高的状态子集。圈内企业的观测-状态映射足够干净，价值估计方差小；圈外企业同等的报表信息量对应的估计方差大——不进圈不是谦虚，是数学。

## 与 pe-as-priced-growth 的接口

PE 是 v*/E 的静态快照，格雷厄姆公式是它的一次参数化（8.5+2g）——两者都只是本砖价值函数在特定假设下的显示解特例。凡是"用单一比率给资产定价"的公式，都可以反向追溯到它对 γ 和 r_t 路径做了什么隐含假设——审计隐含假设就是审计定价公式。
