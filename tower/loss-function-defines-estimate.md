## 论证
Jaynes第13章（13.1+13.9-13.10）：推理输出后验分布，决策=后验×损失函数的期望最小化——两者必须分离，因为同一个后验服务于无限种决策；先验有最大熵/变换群等客观原理，损失函数没有任何对应原理——纯价值判断；不同人不同先验不同损失不同结果完全正常（劳动谈判双方先验近似、损失不同，故能成交——各取所需，与保险同理）。最重案例（13.10）：Ramanujan与Gödel都因不信医生（看错自己的损失函数：认为毒素有害健康）而在本可存活的疾病中早逝——错误的决策不能怪贝叶斯，是损失函数感知错了。第6章（6194-6302行）估计器选择=决策问题：均值vs中位数的选择由损失函数决定不是由数学优雅决定。第14章（14.1-14.4）二元信号检测：所有经典准则（Neyman-Pearson/最小错误概率/极小极大）都是特定损失+先验下的贝叶斯特例；widget工厂（14.6）：纯先验信息的决策——没有新数据也能正确决策，先验细化与数据到达在数学上等价。13.6诚实预报人：激励相容的评分规则可以设计（让预报员报真实概率的机制）——激励结构决定报告的诚实度。

迁移：
1. **目标价的用途声明**：买断方（一次付清，看重均值）、清算方（尾部，看重左分位数）、长期持有者（整条分布的贴现路径）、套利者（时间窗）从同一后验里应取不同的"合理价格"——研报单点目标价不带用途标签是未完成的估计。
2. **"拿不住/卖飞"的第一诊断**：不是知行不一，是损失函数感知错误——把账面回撤的痛苦当真实损失定价；知行合一的决策论解读：知（后验正确）而行错（损失函数感知错误）依然不是真知。
3. **纪律=损失函数外包**：止损位/仓位上限/不做清单的本质=在冷静时把正确感知的损失函数固化为规则，防止临场（情绪态）的感知漂移；这也解释了为什么规则必须在盘外写。
4. **激励审计**：读卖方目标价先读激励结构（评分规则决定报告诚实度）——受激励的报告是特定损失函数下的最优输出，不是后验本身。
