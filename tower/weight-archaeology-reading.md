# 权重考古阅读法（Weight Archaeology）

## 定位
判断力=权重。权重复利的最快合法路径不是机制加速，而是**决策点密度压缩**：自己下场，每年只有 5-10 个真实决策点；考古式阅读，每周可做 30-50 个模拟决策点（30-50× 频率）。代价是单次权重移动幅度小（没有真实回撤砸在身上，consequence-is-last-moat），故**模拟练广度、真仓练深度，两者不可互替**。积累不能省，但积累的时间轴可以从自己人生租借为大师人生。

## 选材筛子：实时账本 > 事后传记
- **Tier 1 实时账本（权重快照，写于结果揭晓之前）**：巴菲特股东信（1957-）、段永平问答录/雪球、索罗斯《金融炼金术》Part 3 实时实验日记（1985-87）、霍华德·马克斯备忘录（1990-，带日期可证伪）、散户乙博客十年。
- **Tier 2 诚实的事后重构（保留决策点结构）**：《英伟达之道》、芒格演讲稿（穷查理宝典）。
- **Tier 3 故事型传记**：作者已替传主完成自我美化（human-brain-as-tower-depreciates），权重被叙事重写，只当纵深轴背景读，不指望练判断力。

## 单次会话协议（45-60 分钟，一个决策点）
1. **选点**：选一封信 / 一组问答 / 一篇备忘录——必须带日期、且当时结果未揭晓。
2. **先写后看**：停在揭晓之前，写下我的裁决——买/卖/持有、假设仓位 %、权重最大的三个变量、证伪集（什么发生=我错了）。
3. **翻页 diff**：对照大师当时实际拍的权重，找冲突点（我拍 30% 他拍 80% 的地方）。
4. **入塔**：diff 值得保留 → 新断言 `tower add`（book: 源一律 principle）；细化既有砖 → `tower note`；经我们自己的实盘/对话验证后才 `tower set --status law --reason`。
5. **节奏**：每周 2-3 个决策点 ≈ 每月 10 个 ≈ 每年 120 个 ≈ 压缩约 20 大师·年。

## 三条纪律
- **先写后看是自我美化的唯一物理防线**——写下预测之前不许翻页。
- **错了不删**：我的错误裁决与大师的相反裁决都保留在塔里（refuted 是资产）。
- **广度深度分工**：考古练识别模式的广度，真仓练承受回撤的深度；考古结论要升级为真仓买入理由，仍须过三核深评（商业模式/企业文化/DCF）。
