# 港美股消费股「低估 · 低位 · 成长」量化筛选系统

由两个 Python 脚本构成的投资研究工具：

- **`fetch_data.py`** — 从权威公开数据源（东方财富、腾讯行情、SEC EDGAR）拉取 **105 只港美股消费股**（港股 43 + 美股 62）的行情、前复权日 K 线与财务数据；
- **`analyze.py`** — 基于**四维评分模型**（估值 / 成长 / 位置 / 质量）对全池量化打分，按「低位 + 低估 + 正增长」硬条件筛选标的，输出 Markdown 研究报告与 CSV 明细。

仓库已附带一份完整数据（2026-08-31）与分析成果，克隆后可直接运行 `python analyze.py` 复现报告。

## 功能特性

| 特性 | 说明 |
|---|---|
| 双脚本解耦 | 拉取与分析分离，数据落盘为 CSV，分析可反复重跑、无需重新联网 |
| 多源冗余 | 东方财富为主源；行情 / K 线被限流时**自动切换腾讯备用源** |
| 权威财务源 | 港股用东财 F10 主要指标；美股用 **SEC EDGAR 官方 XBRL**（companyfacts），自动选择最新概念口径 |
| 增量更新 | 行情 / K 线 / 财务全部增量：已有且新鲜的数据直接复用，二次运行大幅提速 |
| 限流自愈 | 镜像主机轮换 + 自动重试 + 连续失败冷却（75s）+ 备用源接管 |
| 四维评分 | 估值 35% / 成长 30% / 位置 15% / 质量 20%，按市场分组百分位计分 |
| 硬性筛选 | 52 周位置 ≤35%、PE-TTM 为正且 ≤ 池中位数、营收同比 >0、净利率 >0 |
| 重点标的核验 | 对指定标的（默认茶百道 02555、周黑鸭 01458）逐项对照池中位数 / 同业中位数，输出数据结论 |

## 数据源

| 数据 | 主源 | 备用源 | 口径 |
|---|---|---|---|
| 股池行情（批量） | 东方财富 push2 `ulist.np/get` | 腾讯 `qt.gtimg.cn` | 上一交易日收盘 |
| 全市场行情 | 东方财富 push2 `clist/get` 分页 | — | 上一交易日收盘 |
| 日 K 线 | 东方财富 push2his `stock/kline` | 腾讯 `ifzq.gtimg.cn` fqkline | 前复权，近 300 交易日 |
| 港股财务 | 东方财富 datacenter F10 主要指标 | — | 最新 12 个报告期 |
| 美股财务 | **SEC EDGAR companyfacts（XBRL）** | — | 最新完整财年 + 最新季度 |
| 汇率 HKD/CNY | 东方财富 ulist | 固定近似值 0.92 | 实时探测 |

全部接口均为公开网页接口，**无需 API Key**。SEC 官方要求 User-Agent 标识访问用途，脚本已内置合规 UA。

## 评分方法

四维得分（0-100，**按市场分组百分位**，即港股、美股各在自己的消费池内横向比较）：

| 维度 | 权重 | 构成 | 方向 |
|---|---|---|---|
| 估值得分 | 35% | PE(TTM) / PB / PS | 越低分越高 |
| 成长得分 | 30% | 营收同比 / 净利润同比 / 最新季营收同比 | 越高分越高 |
| 位置得分 | 15% | 52 周位置 / 250 日涨跌幅 | 越接近 52 周低点分越高 |
| 质量得分 | 20% | 毛利率 / 净利率 / ROE | 越高分越高 |

**综合机会分** = 四维加权平均（缺失维度按剩余权重归一化；少于 3 维不计综合分）。

**硬筛选条件**（`低估值高成长筛选.csv` 的入选标准）：

1. 52 周位置 ≤ 35%（0 = 52 周最低点，1 = 最高点）
2. PE(TTM) > 0 且 ≤ 所在市场消费池中位数
3. 营收同比 > 0
4. 净利率 > 0

## 快速开始

### 环境要求

- Python 3.10+
- 依赖：pandas、numpy、requests、tabulate

### 安装

```bash
git clone <your-repo-url>
cd consumer-stocks-screener
pip install -r requirements.txt
```

### 运行

```bash
# 1. 拉取数据（增量模式，推荐；首次全量约 20~30 分钟，含限流冷却）
python fetch_data.py

#    仅拉取股池数据、跳过全市场行情（更快，分析不受影响）
python fetch_data.py --fast

#    忽略已有数据，强制全量刷新
python fetch_data.py --refresh

# 2. 分析（读取 data/ 下最新数据，输出到 output/）
python analyze.py
```

### 命令行参数

| 脚本 | 参数 | 说明 |
|---|---|---|
| `fetch_data.py` | `--refresh` | 忽略已有数据，全量刷新 |
| | `--skip-market` / `--fast` | 跳过全市场行情分页拉取 |
| | `--data-dir DIR` | 数据目录（默认 `./data`） |
| `analyze.py` | `--data-dir DIR` | 输入数据目录（默认 `./data`） |
| | `--out-dir DIR` | 输出目录（默认 `./output`） |

- **茶百道（02555.HK）**：现价处于 52 周区间 0% 位置（距高点 -52%），PE 6.8 显著低于港股池中位数 13.1 ——「低估 + 低位」成立；营收 +6.2% 为正但温和，谈不上高增长；股息率 9.5% 提供安全垫。

## 数据口径与已知限制

- 日 K 为**前复权**口径，52 周高低点 / 区间涨跌幅据此计算，与行情软件「不复权」数值略有差异。
- 港股成长口径 = 最新报告期同比（中报 / 年报）；美股 = 最新完整财年同比，两者存在时滞差异。
- 美股 ADR（百威英博、帝亚吉欧、联合利华等）不向 SEC 提交 US-GAAP XBRL，成长指标缺失，评分自动降权。
- 东财 F10 的「每股股息」字段为**近 12 个月累计已派股息**口径，股息率 = 近 12 月每股股息 ÷ 现价（不可再与上年年报相加，否则翻倍高估）。
- 港股市销率 = 总市值(HKD) × 汇率 ÷ TTM 营收(CNY)，汇率自动探测。
- 东方财富行情接口偶发限流 / 断连，脚本内置自动重试、冷却与备用源切换；极端情况下个别标的可能缺失，并记录于 `fetch_manifest.json` 的 `failures`。
- 全市场行情文件（`data/hk_全市场行情_*.csv`、`data/us_全市场行情_*.csv`）体积大且可再生，已通过 `.gitignore` 排除入库。
