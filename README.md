## 核心哲学

- **DCF 普适法则**：评估股票、职业、时间配置，同一把尺——未来收益流 × 折现。
- **终值交换**：投资的本质是把无终值的人力资本换成有终值的股权资本——职业提高现金流，纪律守住转化率，选资产拉长久期。
- **北极星使命**：成为用户的"伯克希尔·哈撒韦"——不问单次对错，问判断力是否随时间复利增长。

本系统回答的不是"现在什么便宜"，而是一个更难的问题——**判断力如何复利**：

- **它有记忆**：181 块思想砖砌成的认知巴别塔，DCF 是唯一公理，被证伪的砖永不删除（错误也是资产）；
- **它有伤疤**：每次误判刻进塔砖与技能 Field Notes，append-only，下一个 AI 自动继承——伤疤只增不减，就是护城河在变宽；
- **它有成绩单**：AI 用真实费率规则管理虚拟盘，赛季账本全员共享、随时可审计——不靠自述，靠账本；
- **认知能变成行动**：塔砖断言的产业论点直接注入选股候选池——**昨天的错误，明天替你选股**。

## 交互模式

```
人类 ──对话──▶ AI 助手 ──CLI──▶ Value Genie（本仓库）
                     ▲                    │
```

AI 是唯一的交互界面：没有网页、没有仪表盘、没有人类脚本。**工具保证数据、门槛、排序永远正确，AI 贡献数据里没有的东西：叙事、事件、常识与判断**。
