你在执行 profile 2.0 战役:对 profiles/ 下 13,641 份 1.0 蒸馏逐簇重写。
1.0 的三大缺陷必须修复:①模板化漂移(同档公司论证文本不可区分);
②同业不可区分(招行与工行不该只差2分,NVDA与摩尔线程不该共用

## 文化评估专节(全员强制,分级打分)

每家公司都必须有文化论证,且要鲜明——这家公司是谁在掌舵、
他过去在钱和危机面前实际做了什么、组织奖励什么人。
文化分全员可打,但按证据级别封顶,论证开头必须标级别:
- A级(有创始人原话/股东信/危机期行为/带日期第三方报道)
  → 分数不限,可进高分区;
- B级(年报+新闻里的行为记录,无创始人一手材料) → 上限 70;
- C级(只有公司自述/官网/简介) → 上限 45,并注明"占位观察分,
  证据升级后重估"。
旧铁律保留:文化分>商业分+5 必须引用至少一条带日期、第三方
可核验的行为事件(v97);文化引用砖统一 benfen-motive-purity+
master-duan,灰区历史进 violated。

## 反模板化专节
- 禁止形容词堆砌("优秀""领先""稳健"不计信息量)。
- 每份论证的事实点必须能让读者遮住公司名仍认出是哪家。
- 同簇公司分数必须体现真实差距;区分不出优劣时宁可整体降档,
  不给平级高分。
- 允许并且鼓励写"反常细节"(这家公司和同行不一样的那一点)。

## 每份自查清单(重写完问自己)
- 遮住公司名,这段论证能认出是这家公司吗?认不出=重写。
- 财报读了吗?网络搜了吗?证据声明写了吗?
- 文化级别(A/B/C)标了吗?分数在封顶线内吗?
- 与簇内最好一家的分差,体现了真实差距吗?
- 分数与锚的关系,能一句话辩护吗?

## 禁止事项
- 不编造未见于证据的事实;数据缺就写缺,不编数。
- 禁止批量复制模板文本;禁止只看公司简介打分。
- 行业常识层知识用到必须申报"行业常识层申报"。
